## 🧮 Formulas that work now also *look* valid, and steadier dragging

This release is mostly about friction: a formula editor that flagged perfectly good formulas as invalid, and a Map view that moved around while you were trying to drag something into place.

### ✅ The formula editor accepts the formulas it always ran

If you build **calculated custom fields**, you may have hit this: a formula that computes correctly still showed as invalid in the editor, so the preview refused to run.

The editor now understands the full formula syntax, including:

- **Lists** — `SUM([${itemEstimate}, ${itemLikelyEstimate}])`, `CONCAT([${itemTitle}, ${itemNumber}])`. This is the form most functions use for a range, and it is what the built-in examples insert when you pick a function from the suggestions.
- **Decimals** — `0.5 * ${itemEstimate}`.
- **True/false and empty values** — `IF(true, 'Yes', 'No')`, `COUNTA([1, null, 3])`.
- **Text with escapes** — apostrophes and line breaks inside quoted text, such as `'it\'s ready'`.

Existing calculated fields are unaffected: every one of them computes exactly the same value as before. This corrects what the **editor** would accept, not what a formula means.

📚 Learn more: [**Setting up custom fields**](/getting-started/admin-onboarding-getting-started/items/setting-up-custom-fields)

### 🖱️ Dragging in the Map view stays put

Two things made dragging rows in the **Map** feel unpredictable, and both are fixed.

The row you grabbed used to disappear the moment you started moving it, so everything below slid up to fill the gap — while your cursor stayed where it was. The drop indicator would then flicker between "reorder here" and "drop inside this one". The grabbed row now **holds its place** for the whole drag and simply goes blank, so nothing shifts underneath you.

Separately, straying a few pixels into the column to the left would immediately hand that column the drop, making the view appear to jump between parents. A column now only takes over once you have **actually paused inside it** — brushing through on your way somewhere else no longer changes anything.

📚 Learn more: [**Using the Map**](/major-modules/workstreams-and-work-items/using-the-map)

### 🔐 Security hardening

Two behind-the-scenes changes to how DevStride handles calculated field formulas and how the app is served in your browser. Formulas are now read and computed directly rather than being run as code, and the browser is given a stricter policy about what it is allowed to execute. Nothing to configure, and no change to what your formulas produce.
