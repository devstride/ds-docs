The DevStride plugin **3.5.1** provides twenty skills for planning, building, reviewing and releasing work. Start with the [Agentic Skills overview](/developer-experience/agentic-skills/claude-code-skills-overview); the [published source and changelog](https://github.com/devstride/claude-plugin/tree/devstride--v3.5.1) define this version's behavior.

| Task | Reference |
|---|---|
| Install or update the plugin in the correct repository and scope | [Getting the Skills](/developer-experience/agentic-skills/getting-the-skills) |
| Detect repository settings and validate local review commands | [Guided Setup](/developer-experience/agentic-skills/setup-guide) |
| Turn an initiative into executable work | [The Planning Loop](/developer-experience/agentic-skills/claude-skills-planning-loop) |
| Build, review and release completed work | [The Delivery Loop](/developer-experience/agentic-skills/claude-skills-delivery-loop) |
| Find any of the twenty commands | [Skill Audit](/developer-experience/agentic-skills/skill-audit) |
| Configure review, session boundaries and release approval | [Configuration Reference](/developer-experience/agentic-skills/configuration-reference) |

Run `/clear` when switching from planning or setup to execution. Local review commands must run read-only; Setup and Doctor check known command templates and identify unverifiable engines. Below-floor defects go beside the plan in a deferred container rather than joining its execution chain. Set `epicIntegrationBranches.autoRelease` to `"ask"` for approval before each completed unit's release.

For existing installs, run `/devstride:update` and follow its reload instructions. Version 3.5.1 fixes updates across project installs and linked worktrees, and permits maintainer-only commits after a release without treating the published plugin as invalid. Repository pins still apply; see [Staying in sync](/developer-experience/agentic-skills/getting-the-skills#staying-in-sync).
